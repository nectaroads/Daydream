# Wonderland Online: Daydream

Daydream is a fan-made take on **Wonderland Online**, with a new Godot client. Explore the world, follow quests, recruit companions, and bring them into turn-based battles. Party up with friends, gather materials and craft gear, or set out to finish one quest and somehow spend the evening fishing.

## Pick a realm

| Realm | Who it's for | How to join |
| --- | --- | --- |
| **Wonderland** | The live realm for regular play. It runs the release version. | Open the `main` branch for the release download. Leave **Beta: Off**, press **Start**, and choose **Wonderland**. |
| **Miracle** | The public beta. New changes land here first, and you may run into rough edges. Characters and progress are separate from Wonderland. | Open the `Beta` branch for the beta download. Turn **Beta: On**, press **Start**, and choose **Miracle**. |
| **Journey** | A local realm for development and testing. It connects to a server running on your own machine. | Start your local Daydream server, then choose **Journey** in the realm list. |

## Download and play

Open this README on the branch for your realm. The download links follow the branch you're viewing. Pick the file for your system and put it in any folder you like. A folder named `Daydream` does the job.

| System | Download | Open it |
| --- | --- | --- |
| Windows (64-bit) | [Daydream.exe](../Daydream.exe?raw=true) | Double-click the executable. |
| Linux (x86_64) | [Daydream](../Daydream?raw=true) | Mark it as executable in your file manager, or run `chmod +x Daydream && ./Daydream` in its folder. |
| macOS (Intel and Apple Silicon) | [Daydream-macOS.zip](../Daydream-macOS.zip?raw=true) | Unzip it and open the app inside. |

One manual download is enough. On your first **Start**, Daydream downloads the game data, verifies the files, and opens the realm list when it's ready. The first download is several gigabytes, so this is a good time to grab a drink. Pick your realm, select a channel, and sign in or create an account.

## Updates, minus the chores

Every time you press **Start**, the launcher checks the selected branch and installs what has changed or is missing. It reuses files that are already up to date, so later updates are usually smaller. If something seems off, **Update** runs a full file check and repairs anything that needs replacing.

If you have an older launcher from when Daydream shipped with a separate game pack, download the current launcher once. It can reuse the game data you already installed.

## Found something weird?

[Open an issue](https://github.com/nectaroads/Daydream/issues/new) and tell us your operating system, which realm you were on, and what you were doing when it happened. Screenshots and exact error messages help.
