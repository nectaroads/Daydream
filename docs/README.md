# Wonderland Online: Daydream

Daydream é um projeto de fãs de Wonderland Online. É aquele RPG de explorar mapas, fazer amizade com companheiros e cair em batalhas por turnos, com um cliente novo feito em Godot. **Miracle** é o servidor Beta, onde as novidades chegam primeiro.

## Bora jogar

Baixe o arquivo do seu sistema e coloque onde quiser. Uma pasta chamada `Daydream` já resolve.

| Sistema | Baixar | Como abrir |
| --- | --- | --- |
| Windows | [Daydream.exe](https://raw.githubusercontent.com/nectaroads/Daydream/Beta/Daydream.exe) | Dois cliques no `.exe`. |
| Linux x86_64 | [Daydream](https://raw.githubusercontent.com/nectaroads/Daydream/Beta/Daydream) | Marque o arquivo como executável ou rode `chmod +x Daydream && ./Daydream` na pasta. |
| macOS Intel e Apple Silicon | [Daydream-macOS.zip](https://raw.githubusercontent.com/nectaroads/Daydream/Beta/Daydream-macOS.zip) | Extraia o ZIP e abra o aplicativo. |

Na tela de atualização, ligue **Beta: On** e clique em **Start**. O primeiro carregamento baixa os dados do jogo e pode demorar um pouco. Depois é só escolher **Miracle**, entrar e jogar.

O arquivo acima é tudo o que você precisa baixar à mão. A cada **Start**, o Daydream confere a versão e baixa o que estiver faltando ou tiver mudado. O botão **Update** serve para conferir e reparar os arquivos quando você quiser.

Se você já tinha o Beta de antes, baixe o arquivo novo uma vez para trocar de launcher. Ele reaproveita os dados que já estão instalados.
